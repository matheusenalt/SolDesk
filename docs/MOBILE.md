# Acesso por navegador móvel

Use a mesma interface e URL web no computador e celular, com HTTPS para acesso remoto.
Android/iOS nativos foram descontinuados; não há SDK nem QR de instalação.
Gravação exige permissão e compatibilidade; digitação sempre disponível.
Não há garantia de PWA/offline ou homologação em aparelho físico.
